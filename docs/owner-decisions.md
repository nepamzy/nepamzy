# Owner decision register

Decisions that engineering cannot safely make. For each: what the code does now, the safe interim behaviour to keep, what happens if nobody decides, whether it blocks a supervised pilot, and who must decide. **No answer here has been invented**; the "current" column describes code, not policy.

Already decided and preserved (not reopened): support refund-approval limit **₦0** (finance approves and executes; requester cannot approve or execute their own request); **only the account holder completes a delivery**; **customer-arranged returns**, no automatic restock, no automatic refund, no rider return tasks; internal proof token hidden from riders and no QR; **drawn signature mandatory**, typed acknowledgement **disabled**; rider cap five, one active rider per order, arrival inferred by the server, GPS never completes an order.

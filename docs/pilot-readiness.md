# Pilot-readiness checklist (Batch 6)

**This system is NOT pilot-ready and NOT production-ready.** It has not been deployed, handles no real money, sends no real messages, holds no real campus coordinates and has no production data. This checklist lists what stands between the current code and a supervised pilot. It is **not** a self-certification: every row marked anything other than "Verified externally" has not been confirmed by anyone outside the engineering sessions, and **no independent security audit has taken place**. "Tested locally" means automated tests in this repository pass on a local stack, nothing more.

## Honest summary

- **What exists and is exercised locally:** accounts with mandatory second factor for privileged roles, marketplace and checkout, test-mode payments against a local fake provider, order state machine, shop operations, riders and capacity, tracking with synthetic data, recipient-only delivery completion with a drawn signature, a refund/return/report workflow with a fake refund provider, in-app notifications, reviews with moderation, role-scoped administration, an audit trail, and a large automated test suite.
- **What blocks any real use:** items 1–5, 8, 12–14, 21–24 are not engineering problems and cannot be closed by more code. Items 15–16 and 29–30 are operations work that needs decisions and money.
- **Residual risks the engineering team can name:** see `docs/known-issues.md` (K-numbers above) and `docs/security-privacy.md` §4.

## Post-Batch 6 remediation status (see `docs/reports/post-batch-6-remediation.md`)

Technically prepared to the extent demonstrated locally; **blocked from a pilot** by the prerequisites above that no code can supply: AFIT authorisation, approved places and terms, rider verification, privacy/retention and payment decisions, an accessible proof alternative, an independent security review, scheduling and monitoring that someone actually operates, backups and incident response, pilot scope. The full decision list is `docs/owner-decisions.md`. Nothing in this remediation authorises a pilot.
